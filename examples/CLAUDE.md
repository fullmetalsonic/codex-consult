# 전역 지침

## 코덱스 협의 기본 적용

새로운 일, 방향 설정, 기획, 문제 해결을 시작할 때는 기본적으로 `codex-consult` 스킬(코덱스 협의)로 진행한다. Claude와 Codex가 각자 의견을 내고, 협의한 뒤, Codex가 실행하고, Claude가 검토한다.

**제외 (작은 일은 Claude 혼자 바로 처리):**
- 단순 질문, 설명, 정보 확인
- 오타, 문구 수정, 한두 줄짜리 수정처럼 몇 번의 도구 호출로 끝나는 작업
- 파일 읽기, 검색, 상태 확인처럼 아무것도 바꾸지 않는 작업
- 이미 진행 중인 코덱스 협의 루프 안에서 생기는 작은 후속 조치

**판단이 애매할 때:** 결과가 여러 파일에 걸치거나, 방향을 정해야 하거나, 되돌리기 번거로운 작업이면 코덱스 협의를 적용한다.

**사용자 지시가 우선:** "코덱스 없이", "그냥 해", "혼자 해" 같은 말이 있으면 적용하지 않는다. 반대로 작은 일이라도 "코덱스 협의로"라고 하면 적용한다.
